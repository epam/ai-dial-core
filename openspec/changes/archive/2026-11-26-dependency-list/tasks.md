# Tasks

Class names are in `server/src/main/java/com/epam/aidial/core/server`; tests are in `server/src/test/java/com/epam/aidial/core/server/`
(API tests at that level, unit tests under `service/`, `controller/`, `validation/`). Each spec scenario is named by the test class in the task
that covers it; scenario names are the headers in `specs/dependency-listing/spec.md`. A scenario about a reference rule, the walk or a policy is
covered by a unit test; the API tests cover only the HTTP boundary (route, statuses, shape of the answer, the end-to-end behaviour of a policy).
No setting, `docs/dynamic-settings/*.md` page or `CLAUDE.md` text changes, because the feature adds no setting.
