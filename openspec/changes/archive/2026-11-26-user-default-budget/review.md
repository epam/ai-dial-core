# Review

## What shipped

- `GET` and `PUT /v1/user/budgets/default`: a user signed in with a JWT sets, reads and clears (`{"budget": null}`)
  their default budget. PUT accepts only a budget the caller holds now, the set `GET /v1/user/limits` lists, and
  answers 400 with one message for any other id. A default whose budget is withdrawn or expired reads as unset and
  stays stored. API keys and per-request keys get 403.
- The private record type `user_budget_default` in the user's bucket, unmapped in `ResourceTypes.of` and not
  published as an event. `DefaultBudgetService.findDefault` is the read helper for #2365.
- Docs: "Default budget" in `docs/dynamic-settings/policies.md`; OpenAPI annotations (`docs/open_api_core.yaml` is
  regenerated by CI).
