# Review

## What shipped

- Identity provider setting `costObjectPath`; `projectPath` is read when it is the only one, with a deprecation
  warning at start, and ignored with a warning when both are set.
- `CostObject.resolve` (claim, key project, `defaultCostObject`) with its source; `ProxyContext.getCostObject()` /
  `getCostObjectSource()`; `BudgetEnforcer.resolveCostObject` uses it. `getProject()` / `getUserProject()` answer as
  before.
- `GET /v1/user/info` adds `costObject` and `costObjectSource`; analytics rows add `cost_object.{id,source}` after
  `spending_limits`; background job records carry both; the OTel JSON layout adds `user.cost_object` and
  `user.cost_object.source`.
- Docs: README, policies, plugins, Claude Code and Codex spend limits, sample settings, `UserInfoResponse` schema.
