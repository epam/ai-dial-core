# Fixtures in translation-fixtures/ that the Java translation does not match yet.
#
# Read by TranslationFixtureParityTest. One fixture per line:
#
#   <kind>/<file> <change id>
#
# A listed fixture that fails is skipped. The test fails when a listed fixture passes, when an unlisted
# in-scope fixture fails, and when a line names a fixture that is missing or out of scope. So the list can
# only shrink: a change that makes a fixture pass deletes its line.
#
# The change id is the fixture's owner, the last change of the series it needs, read from the fixture's
# `features`, a request's `output_config` and the event type of each stream `handle` call:
#   - a response fixture, or a stream fixture with an `emit_error` call: builtin-translator-non-streaming-errors;
#   - else one that needs reasoning (a feature among reasoning, thinking, redacted_thinking, summary_text,
#     reasoning_text, field:thinking, omit_thinking, adaptive, enabled, disabled; an `output_config` holding
#     `effort`; or an event type starting with `response.reasoning_`): builtin-translator-reasoning;
#   - else one that needs tools (a feature among field:tools, field:tool_choice, function_call, tool_use,
#     tool_result; or the event type response.function_call_arguments.delta or .done): builtin-translator-tools;
#   - else builtin-translator-fixture-parity.
#
# Refreshing the fixtures: rerun the recorder in the Python translator repository, delete translation-fixtures/,
# copy the recorder's new output in its place, run TranslationFixtureParityTest and update this list.
